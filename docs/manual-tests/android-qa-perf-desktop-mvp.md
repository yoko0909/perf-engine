# Android QA 桌面性能 MVP 手工验收清单

## 启动前准备

1. Windows 主机已安装 Python 3.14、Node.js 和 ADB。
2. 已执行 `python -m pytest tests -q`，确认后端自动化测试通过。
3. 已执行 `npm.cmd --prefix ui run test` 和 `npm.cmd --prefix ui run build`，确认前端测试和构建通过。
4. Android 设备已打开开发者模式和 USB 调试。

## 真机验收步骤

- [ ] 无设备时启动程序，顶部区域可用，状态区显示“未检测到 Android 设备”。
- [ ] 连接设备后点击“刷新设备”，设备下拉框出现正确机型和序列号。
- [ ] 选择设备后，应用下拉框成功加载三方应用列表。
- [ ] 选择应用后点击“开始采集”，设备和应用选择框被禁用，按钮切换为“停止采集”。
- [ ] 采集中页面每秒刷新一次，FPS、Frame Time、App CPU、Total CPU、Memory、Temperature 六张图表持续滚动。
- [ ] 状态卡同步展示连接状态、设备名称、屏幕状态、应用状态、电量、温度和最近刷新时间。
- [ ] 点击“停止采集”后，图表停止刷新，最后一屏数据保留在页面上。
- [ ] 采集中拔掉数据线，页面提示“设备已断开”，并停止轮询。
- [ ] 采集中手动关闭目标应用，页面提示“目标应用已退出”，并停止轮询。
- [ ] 采集中锁屏或熄屏，状态卡展示 `screen_state=off` 或 `unknown`，页面保持稳定。

## 当前执行状态

- 自动化验证已完成。
- 真机验收尚未在当前工作区执行，需要实际 Android 设备配合完成上面的 10 项检查。

## 已知限制

- 当前版本只支持单设备、单应用、单会话。
- 当前版本不支持导出报告、历史会话管理和截图时间轴。
- 当前版本不支持 iOS 或 Windows 采集。
- 前端构建产物包含 ECharts，生产包体偏大，后续可以按图表分包优化。
